# User Stories Wireframes on the Word Document
## 1 As a Member of a Community, I would like to see a list of my immediate tasks because I want to manage the things I must do.
## 2 As a Member of the Community, I want to be able to see these tasks clearly in a format that helps to maintain life order.
## 3 As a busy person I want to add a new task quickly in the main view capturing new ideas without interupting thought flow.
## 4 As a busy person, I want to be able to delete tasks safely with little effort but it must have safeguards.
## 5 As a first time user, Getting help should be quick and easy as should be orientation and creating my 1st list.
