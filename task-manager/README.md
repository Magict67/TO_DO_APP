# Community Task Manager
**A Comprehensive React-Redux Application**

## Project Overview
### This application is a task management system for community collaboration. Allowing users to track tasks, filter them by status, and contact the administration through a controlled form.

## Features
* **Full CRUD Functionality**: Create, Read, Update (Toggle), and Delete tasks.
* **Redux State Management**: Centralized store for predictable state transitions across the app.
* **Advanced Filtering**: Sort tasks into "All", "Active", and "Completed" views.
* **React Router**: Seamless navigation between the Task Dashboard and the Contact page.
* **Responsive Design**: A side-by-side layout using modern CSS Flexbox.

## Technical Requirements Met
* **Controlled Form**: Includes validation and state-handling for 4 distinct fields.
* **Custom Styling**: Over 10 unique CSS rules for branding and layout.
* **Single Page Application (SPA)**: Uses `react-router-dom` for no-refresh navigation.

## 6 ideas for future improvement
* **User Authenticate & Profiles**: Registration and Login System.
* **Backend Integrate MySQL**: Use a permanent database.
* **Add Deadlines and Notifications**: Due Date.
* **Forum Integration**: Allow community commenting with messaging system.
* **Priority Listing**: Color code low medium and high priority.
* **Progress Graphing**: Provide a visual to show tasks on a scale gradient
