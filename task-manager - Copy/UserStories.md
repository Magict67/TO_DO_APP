# User Stories - Community Task Manager

1. **Task Visibility**: As a user, I want all my community tasks in a clear list so to stay organized.
2. **Completion Tracking**: As a user, I want to click/mark it strike-through so I know it's done.
3. **Filtering**: As a user, I want to filter tasks "Active"/"Completed" to focus on remaining work.
4. **Data Entry**: As a user, I want to fill contact form reach community leads with personal info and comments.
5. **Navigation**: As a user, I want to switch between task list and contact page without website reloading.
